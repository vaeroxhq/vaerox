## Overview

Vareox is an engineering studio that designs and builds production-grade AI systems, backend platforms, developer tooling, and intelligent infrastructure. We work at the intersection of applied artificial intelligence and distributed systems, delivering solutions that prioritize reliability and maintainability.

This repository contains the studio's public website—a technical portfolio that documents our engineering practices, research, and architectural decisions. The platform serves as both our digital presence and a reference for how we approach complex engineering problems.

---

## Philosophy

We believe software should earn trust through engineering, not marketing. Our work is guided by a simple principle: build systems that survive production, not presentations.

This means:
- Prioritizing clarity over complexity
- Writing code that is both functional and readable
- Designing for long-term maintainability
- Making deliberate, defensible technical decisions

We operate with a quiet confidence, letting the quality of our systems speak for itself.

## Technology

The website is built with a modern, static-first architecture:

- **React 19** — UI development
- **TanStack Start** — Full-stack React framework
- **TanStack Router** — Type-safe routing with search params
- **TypeScript** — Static type safety
- **Vite** — Build tooling and development server
- **Tailwind CSS** — Utility-first styling
- **shadcn/ui** — Accessible component primitives
- **Radix UI** — Unstyled, accessible components

## Development

Clone the repository:

```bash
git clone https://github.com/vaeroxhq/vaerox.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Architecture

The site follows a static-first approach with incremental enhancements. Content is pre-rendered where possible, with client-side hydration for interactive features. The architecture prioritizes:

- **Fast initial load times** — Minimal JavaScript overhead
- **Progressive enhancement** — Core content works without JavaScript
- **Type safety** — Full TypeScript coverage across the codebase
- **Cache optimization** — Strategic caching for assets and API responses

---

## Design Principles

The interface follows a restrained, engineering-first design philosophy:

- **Minimal over decorative** — Every visual element serves a purpose
- **Performance over effects** — Animations and transitions are purposeful and performant
- **Consistency over complexity** — Reusable patterns and predictable behavior
- **Accessibility by default** — Accessible from the start, not as an afterthought
- **Motion with purpose** — Animation enhances understanding, not distraction
